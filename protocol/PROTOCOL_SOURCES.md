# V2 protocol source identity

The complete MonReader V2 action plan, execution phase plan, protocol audit, and fresh-chat handoff are maintained as project control sources outside the final public deliverable.

Their immutable SHA-256 fingerprints are recorded in `PROJECT_STATE.yaml`.

For implementation, scientific precedence is:

1. latest explicit user-approved rule;
2. MonReader V2 Action Plan;
3. MonReader V2 Execution Phase Plan;
4. frozen 20-candidate JSON bank;
5. verified V2 manifests/run artifacts as evidence only.

Historical code, old notebooks, old W&B material, old split IDs, validation/Bayesian tuning, and pre-reset metrics do not override V2.
